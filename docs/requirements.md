## 已採用的假設

- 框架選 Vue 3，使用官方完整 production global build，存放專案內。
- 原生版完成全部要求；Vue 版完成指定三項功能與統計。
- 不新增登入、分類、編輯或資料持久化；重新整理會清空任務。
- 所有截圖使用測試任務，不包含個人資料。
- AI 生成與自動測試的紀錄不等同學生親自完成／測試的聲明。
- GitHub 公開發布前，先讓使用者檢視可執行成果。
