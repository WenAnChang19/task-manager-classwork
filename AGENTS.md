# Task Manager classroom project

- This is a small static HTML/CSS/JavaScript exercise with a separate Vue version.
- Keep UI text in Traditional Chinese and source easy for a beginner to explain.
- Vanilla and Vue task arrays are independent. Tasks reset on reload.
- Avoid unrelated features, build systems, tracking, external fonts and persistence.
- Use relative paths so the folder works under a GitHub Pages repository subpath.
- Use real DOM controls; render user text as text, never as HTML.
- Validate add, blank input, toggle both ways, delete, all three filters, counters,
  keyboard operation, narrow widths and the separate Vue page in Chromium.
- Record automated evidence truthfully; never claim the student personally ran it.
- Do not fabricate AI conversations or the student's personal reflections.
- No credentials or personal runtime files in this repository.

## Commands

- Preview: `python3 -m http.server 8765 --bind 127.0.0.1`
- Syntax: `node --check app.js` and `node --check vue-app.js`
- Browser tests: `npm install` then `npm test`

## Ownership during this task

- Implementer: `index.html`, `vue.html`, `styles.css`, `app.js`, `vue-app.js`,
  `vendor/`, `THIRD_PARTY_NOTICES.md`, `.nojekyll`.
- Coordinator: documentation, test harness, test reports and evidence.
- Other agents are read-only or may create test/evidence artifacts only.
